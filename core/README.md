# Core

O Core contém apenas capacidades e princípios que devem fazer sentido para a maioria dos projetos.

## Escopo inicial

- discovery do projeto;
- definição e documentação de arquitetura;
- quality gates;
- estratégia mínima de testes;
- preservação de comportamento;
- refatoração em lotes pequenos;
- revisão de código;
- segurança e classificação de risco;
- mapa de contexto para agentes.

## Regra

Se uma prática depende fortemente de domínio, framework, fornecedor ou operação específica, ela não pertence ao Core por padrão.
