# Prompts

Prompts do Toolkit Zero são procedimentos versionados para agentes, não apenas instruções soltas.

## Categorias iniciais

- `discovery/`
- `planning/`
- `implementation/`
- `refactoring/`
- `testing/`
- `review/`
- `security/`
- `maintenance/`

## Requisitos

Todo prompt relevante deve declarar objetivo, pré-condições, limites, critérios de parada, validações e o que não deve ser alterado.
