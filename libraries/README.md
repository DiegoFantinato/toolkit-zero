# Libraries

Código executável reutilizável do Toolkit Zero.

## Política

- código externo relevante deve ser internalizado conscientemente, não consumido cegamente;
- cada biblioteca deve possuir versão, testes e changelog aplicável;
- dependências devem ser controladas;
- alterações devem preservar compatibilidade sempre que possível;
- regras de arquitetura específicas devem ser opt-in.

## Primeira biblioteca planejada

`eslint-quality/` — quality gates para tamanho de arquivo, uso direto de console e acesso direto a dados, com presets modulares e testes permanentes.
