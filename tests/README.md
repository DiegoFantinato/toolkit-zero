# Tests

O Toolkit Zero mantém testes permanentes para código executável e regras reutilizáveis.

## Objetivos

- detectar regressões;
- reduzir falsos positivos;
- validar compatibilidade após atualização de dependências;
- proteger comportamento antes de promoção de mudanças.

Testes temporários podem existir durante experimentos, mas regras oficiais devem ter cobertura de regressão permanente.
