# Modules

Módulos adicionam capacidades opcionais sem contaminar o Core.

Cada módulo deve declarar:

- objetivo e casos de uso;
- status de maturidade;
- dependências;
- riscos;
- versão;
- testes aplicáveis;
- critérios de promoção/depreciação;
- origem/proveniência quando derivado de fonte externa.

Exemplos futuros: scraping, automação comercial, conciliação fiscal, WhatsApp, CRM, pagamentos, agentes e otimização de contexto.
